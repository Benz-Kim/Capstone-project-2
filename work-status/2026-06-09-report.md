## 오늘 작업 보고서

### 1. 주요 작업 내용
- Google / Apple 소셜 로그인 구조를 실제 OAuth 방식으로 바꾸는 작업 진행
- Apple 로그인은 우선 제거하고 Google 로그인만 실제 연동되도록 정리
- Google Cloud Console에서 OAuth consent screen과 Web OAuth client 생성
- 로컬 개발 환경에서 OAuth가 동작하도록 `localhost`와 `127.0.0.1` origin 설정 반영
- 소셜 로그인 설정 과정을 차근차근 따라 할 수 있도록 `SOCIAL_LOGIN_SETUP_GUIDE.md` 추가

### 2. 버그 수정 및 개선
- `origin_mismatch` 오류 원인 확인 및 수정
  - 앱을 `file://`가 아니라 로컬 서버에서 실행하도록 전환
  - Google OAuth client의 Authorized JavaScript origins와 redirect URI를 로컬 주소로 등록
- Google 로그인 팝업이 브라우저에서 막히는 현상 확인
  - origin mismatch는 해결됐지만, 현재는 popup 차단/브라우저 동작 확인이 추가로 필요
- Apple 로그인은 나중에 다시 붙일 수 있도록 코드 구조는 유지한 채 Google-only로 정리
