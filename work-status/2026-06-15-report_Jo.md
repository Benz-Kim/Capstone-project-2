## 작업 보고서 — 2026-06-15

### 1. 주요 작업 내용

#### 하단 네비게이션 바 (5개 탭) 추가
- **Home** — 기존 대시보드 (Goal Card, Stepping Stones, Milestone Bars, Tasks, Bible Verse)
- **Roadmap** — 마일스톤 전체 타임라인, 진행도 바, 포커스 과목 표시
- **AI Coach** — 풀스크린 채팅 UI (Gemini API 연동 준비 완료)
- **Progress** — 오늘 완료율 링 차트 + 7일 바 차트 + 스트릭 카운터
- **Profile** — 유저 정보 / Gemini API 키 설정 / 로그아웃

#### AI 모델 연동 준비 (`js/ai.js` 신규)
- Gemini 2.0 Flash API fetch 함수 (`askGemini()`)
- 유저 목표·트랙·할 일 기반 시스템 프롬프트 빌더
- localStorage 기반 API 키 관리 (`getGeminiKey / setGeminiKey`)
- 일별 학습 진행률 저장 (`saveDailyProgress`)
- 스트릭 계산 (`getStreak`)
