# Work Status Reports

This folder is for saving daily or periodic work reports, tasks, and progress notes.

## Usage

- Create a new Markdown file for each report, e.g. `2026-06-08-report.md`.
- Store summaries of work done, bug fixes, and next steps.
- Keep the file names consistent so it's easy to browse later.

## Example

- `2026-06-08-report.md`: Today’s work summary and completed tasks.
- `2026-06-09-plan.md`: Planned work items and upcoming changes.
